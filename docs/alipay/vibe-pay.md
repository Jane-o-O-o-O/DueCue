## 一、产品概述

Vibe Pay 是面向 AI 创作者的应用商业化收款方案，帮助创作者将由 AI 创建或驱动的网页应用、移动应用快速变成可持续经营的产品。

Vibe Pay 复用成熟的支付能力，同时提供更适合 AI 创作方式的接入路径。无论是个人创作者，还是有技术团队的应用开发者，都可以根据自身对定制自由度和上线效率的需求，选择合适的产品模式。

## 二、适用对象

Vibe Pay 适用于以下类型的用户和应用：

- 使用 AI 创建网页应用、移动应用的个人创作者；
- 通过自然语言编程或 Vibe Coding 开发应用的创作者；
- 需要为 AI 功能、数字内容或应用权益收费的开发者；
- 希望快速验证商业模式、减少支付配套开发投入的应用团队；
- 需要高度定制支付流程和商业化体验的技术团队。

## 三、两种模式

Vibe Pay 提供两种模式，分别对应“高度定制”和“快速上线”两类诉求。

### 3.1 基础收款能力

**定位**：提供支付、订单查询、退款等原子能力，由创作者自行设计和建设应用的商业化配套。

**适合谁**：

- 需要高度定制支付体验的创作者或技术团队；
- 希望自行设计付款入口、业务流程和应用界面的开发者；
- 愿意自行建设订单、权益等应用商业化配套的团队。

**接入方式**：

通过 Skill 一句话接入。创作者将接入命令复制给 Agent，由 Agent 结合应用上下文和应用形态，协助匹配网页或移动应用的接入路径。

**能力特点**：

- 支持网页应用与移动应用；
- 支持支付、订单查询、退款等核心原子能力；
- 支持创作者自行设计付款时机、支付页面和业务流程；
- 支持创作者自行建设订单和权益管理等配套能力。

> 基础收款能力的具体产品能力、接口范围、接入要求和技术流程，详见后续产品文档：[AI网页应用收款](https://aipay.alipay.com/docs/vibe-pay/ai-web-app-payment-qianyi/ai-web-app-payment-integration-guide.html)、[AI移动应用收款](https://aipay.alipay.com/docs/vibe-pay/mobile-app-pay/app-pay-integration-guide-new.html)

复制给Agent，开始接入
```ts
npx -y @alipay/alipay-aipay@latest install
```


### 3.2 智能收款套件

**定位**：将支付及相关商业化配套组合提供，帮助创作者更快上线完整的应用商业闭环。

**适合谁**：

- 希望快速验证 AI 应用商业模式的创作者；
- 不希望重复建设订单和权益管理等交易配套的创作者；
- 希望将开发精力集中在应用功能和用户体验上的团队；
- 通过合作平台创作或入驻应用的创作者。

**接入方式**：

当前暂以合作平台为入口。创作者通过已合作平台接入智能收款套件，由合作平台提供相应的商业化能力。

创作者独立接入能力正在准备中，敬请期待。

> 智能收款套件的具体产品能力、接口范围、接入要求和技术流程，详见产品文档：[即刻收](https://aipay.alipay.com/docs/vibe-pay/nowpay/nowpay-intro.html)

## 四、两种模式如何选择

| 你的诉求 | 建议模式 |
| --- | --- |
| 想自己掌控支付页面、业务流程和商业化体验 | 基础收款能力 |
| 有技术团队，愿意自行建设订单和权益等配套 | 基础收款能力 |
| 希望通过 Skill 快速接入网页或移动应用 | 基础收款能力 |
| 希望快速验证应用是否适合收费 | 智能收款套件 |
| 不想重复建设订单与权益管理 | 智能收款套件 |
| 已在合作平台创作或入驻应用 | 智能收款套件 |
